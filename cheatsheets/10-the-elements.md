# Sheet 10 · The Elements (Lesson 10)

*Words on this sheet:* **timing** = how many frames · **spacing** = distance per frame · **onion skin** = ghost view of neighbouring frames.

**ELECTRICITY — no body:**

- ☐ Jagged segments, sharp angles, branching forks
- ☐ Redraw a NEW random bolt every frame — ignore the onion skin (discontinuity = crackle)
- ☐ ~6 fps, 6 frames, glow layer ("Add (Glow)" mode in Clip Studio)
- ☐ Zero follow-through

**WATER — all body:**

- ☐ Simple readable masses, smooth muscular curves
- ☐ Crest lags base (overlap champion) · droplets = tiny balls on arcs
- ☐ Splash: impact → rim → columns/droplets (hang at top) → fall → late soft ripples

**FIRE — buoyant appetite:**

- ☐ Base leads, tips die: ASCENT → SWELLING → DIVISION → REDUCTION
- ☐ Never holds a shape; S-curves with sharp licks; few tongues, not scribble
- ☐ Candle = gentle sway · blaze = fast, big licks, sparks arrive late

**WIND — invisible:**

- ☐ Draw only its VICTIMS: hair, cloth, leaves, dust
- ☐ It's a traveling push: near things react BEFORE far things
- ☐ Gust → then recovery, each thing on its own schedule (overshoot, settle)
- ☐ Hair loop: 24 frames, keys every 3, softness over volume
