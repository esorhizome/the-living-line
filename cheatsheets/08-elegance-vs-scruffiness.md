# Sheet 8 · Elegance vs Scruffiness (Lesson 8)

*Words on this sheet:* **arc** = curved path of motion · **spacing** = distance moved per frame · **overshoot & settle** = pass the target, ease back · **boiling** = redrawn lines shimmering frame to frame — noise when accidental, texture when chosen.

> Two dialects of the same language. Neither is better. The only failure is the *accidental* version.

| Dial | Elegant | Scruffy |
|---|---|---|
| Arcs | long, unbroken | kinked, jittery |
| Spacing | evenly graded, cushioned ends | lurches and hesitations |
| Timing | unhurried, consistent | syncopated; quick-quick-slow |
| Overshoot | barely-there, long soft settle | floppy, bouncy multi-hit settles |
| Follow-through | restrained, silk-like | everything flapping |
| Line of action | long, lifted | compressed, slumped |
| Silhouette | clean, simple | busy, spiky, delightfully messy |
| Line quality | few confident strokes | sketchy strokes, deliberate boiling |
| Symmetry | composed near-symmetry | cheerful dishevelment |

**Remember:**

- ☐ Speed is NOT the dialect — a fencer's lunge is fast *and* elegant; a hungover shuffle is slow *and* scruffy
- ☐ The dialect lives in *quality of path and stop*
- ☐ Cross-cast for comedy: scruffy ballerina, elegant scarecrow
