# Sheet 2 · The Twelve Principles (Lesson 2)

*Where they come from:* Disney veterans **Frank Thomas & Ollie Johnston**, *The Illusion of Life* (1981). They are levers, not laws — every one is a personality dial.

**The chant (twelve beats, in order — say it until it says itself):**

> **Squish · wind-up · stage it · plan-or-don't ·**
> **lag · ease · curve · fidget ·**
> **clock it · push it · weigh it · charm.**

| Beat | Principle | Personality lever |
|---|---|---|
| Squish | **Squash & stretch** — flatten under impact, lengthen with speed, volume constant | lots = bouncy, comic · none = stiff, dignified |
| Wind-up | **Anticipation** — small prep move before the action | big = theatrical · tiny = professional · none = alien |
| Stage it | **Staging** — present the action so it reads instantly | framing tells the audience how to feel |
| Plan-or-don't | **Straight-ahead / pose-to-pose** — discover frame by frame, or plan keys first | wild energy vs deliberate control |
| Lag | **Follow-through & overlap** — loose parts trail; nothing starts/stops in unison | the difference between alive and cardboard |
| Ease | **Slow in / slow out** — bunch drawings at both ends of a move | deep = graceful · none = mechanical, eerie |
| Curve | **Arcs** — natural motion travels curved paths | smooth arcs = elegance · jagged = chaos, panic |
| Fidget | **Secondary action** — small supporting action layered on the main one | a diary of who the character is |
| Clock it | **Timing** — how many frames an action takes | quick = eager, twitchy · slow = weary, grand |
| Push it | **Exaggeration** — push past real life so it reads | sets the register: naturalism → full cartoon |
| Weigh it | **Solid drawing** — forms with weight, volume, structure | credible from any angle |
| Charm | **Appeal** — order (clarity) + interest (surprise) | villains can drip with it too |
