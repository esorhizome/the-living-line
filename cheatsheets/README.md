# The Cheat Sheets

One sheet per lesson, each sized to be **screenshotted onto a phone** or printed and taped to the desk. Every sheet re-defines its own jargon, so none of them require you to remember anything — that's the whole design. Screenshot the ones for whatever you're drilling this week; ignore the rest until they're needed.
