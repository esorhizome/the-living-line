# The Living Line

**A hand-drawn animation guide to personality, persona & appeal** — written for people who animate in [Clip Studio Paint EX](https://www.clipstudio.net/en/) at a desk and [ibisPaint X](https://ibispaint.com/) on a phone, and whose attention span deserves to be designed for rather than apologized about.

The guide's one thesis: personality in animation is not *what* a character does — it is *how the drawings choose to do it*. The same head-turn, re-timed, reads as shy, smug, alien, dignified, or exhausted. Every lesson teaches the dials that make that choice.

## The whole book in four letters

> **Cause first → body next → loose parts last → settle.**
>
> **C·B·L·S — "Cool Bodies Lag Softly."**

Animate the thing that causes the motion, then the body that carries it, then the loose things that react, then let everything ease into stillness. Every lesson is that sentence in a different costume. (The twelve classic principles get their own twelve-beat memory chant in Lesson 2.)

## What's in the repo

- **[The full guide](The_Living_Line_Guide.md)** — 15 standalone lessons. *Standalone* is a promise: open the book anywhere; no lesson requires you to remember an earlier one, and jargon is re-defined every single time it appears — by design, not accident.
- **[Cheat sheets](cheatsheets/)** — one per lesson, sized for a phone screenshot or a printout by the desk. Also available as [one printable file](The_Living_Line_Cheat_Sheets.md). The sheets are the guide's short-term memory, so the guide never has to be re-read to be used.

## Housekeeping notes

- **Every link was fetched and verified live on 16 August 2026.** Only free *and* clearly legal sources are cited: creators' own channels, official documentation, Wikipedia, Khan Academy, and genuinely public-domain films on the Internet Archive. One 2010 tutorial whose site retired it is cited via its Wayback Machine snapshot.
- **The code in Lesson 14** was checked against the engines' current official documentation the same day, and the web (CSS/JavaScript) examples were run in a real browser.
- Drills assume 15–25 minutes a sitting. A skipped day is a skipped day; the practice loop is a carousel, not a ladder.
